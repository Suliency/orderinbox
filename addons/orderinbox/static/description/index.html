Review emailed customer purchase orders in Odoo — and approve them into draft sales orders

OrderInbox AI is the in-Odoo review queue for customer purchase orders that arrive by email. The companion OrderInbox appliance watches your orders inbox, reads every PO in any format (PDF, Excel, CSV, plain email), matches the customer and every SKU against your live Odoo catalog, and validates quantities, prices, pack sizes and duplicates — then pushes the results here for a one-click decision.

Draft-first, by design: approving creates a draft sales order in your Odoo. Nothing is confirmed until your team posts it, the normal way.

What this module gives you in Odoo

  • Review queue kanban — Ready for approval / Exceptions / Draft created / Rejected, with the validation issues visible on the card
  • Per-line match scores — every SKU shows how it was matched (exact, alias, fuzzy or LLM) and the confidence, so you know what to trust
  • Validation issues with suggested fixes — pack-size violations, price deviations, duplicate PO numbers, currency checks
  • One-click Approve — builds a draft sale.order from the matched lines (customer, PO reference, quantities, quoted prices)
  • One-click Reject with a reason, logged to the chatter
  • Automatic sync — a cron polls the appliance every 5 minutes; you can also push orders to /orderinbox/sync
  • Settings page — appliance URL, API token, match threshold, price tolerance, accepted currencies
  • Standalone mode — no appliance? Create orders manually (or via the API) and approve them here; drafts are built entirely in Odoo

How it fits together

The heavy lifting (inbox monitoring, document extraction, local LLM inference, deterministic validation) runs in the OrderInbox appliance — a Docker container on your own network. Documents never leave your infrastructure. This module is the face inside Odoo: 

Customer email ──▶ OrderInbox appliance (Docker)
                    • watches the inbox (IMAP)
                    • reads PDF / XLSX / CSV / email
                    • matches customer + SKUs vs live Odoo catalog
                    • validates: packs, min order, prices, duplicates
                    • local LLM (Qwen via Ollama) only where tables can't help
                         │
                         │  token-authenticated sync (every 5 min)
                         ▼
             This module — kanban review queue in Odoo
                         │
                 human approves ▼
            draft sale.order in Odoo (you post it)

Installation & setup

  1. Install the module from the Odoo Apps Store (or add the addons path to your Odoo and install orderinbox).
  2. Deploy the OrderInbox appliance (Docker image orderinbox-ai) and point it at your Odoo: ODOO_MODE=live ODOO_URL=… ODOO_DB=… ODOO_USERNAME=… ODOO_PASSWORD=… plus the orders mailbox (IMAP_* or Gmail).
  3. Set ORDERINBOX_API_TOKEN on the appliance and enter the same token in Settings → OrderInbox along with the appliance URL (e.g. http://appliance.lan:8501).
  4. Orders start appearing in the queue. Approve the good ones, fix or reject the exceptions.
External service notice: this module syncs with an external OrderInbox appliance over HTTP using a shared token. Without an appliance it still works standalone: create records manually or via the /orderinbox/sync endpoint and approve them in Odoo.
